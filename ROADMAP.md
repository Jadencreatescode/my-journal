# Roadmap

The roadmap describes direction, not a release promise. Compatibility and availability claims remain tied to verified releases.

## Current priorities

1. Make first use understandable through a synthetic demonstration that reads no user data.
2. Keep Linux, macOS, Ubuntu under WSL, and the documented native Windows helper route reproducible.
3. Improve accessibility, installation diagnostics, and privacy safe support reports.
4. Expand examples for long projects, creative work, operations, and software development using synthetic data.
5. Keep release archives deterministic, independently reviewable, and bound to exact source.

## Contribution sized work

See `docs/GOOD_FIRST_ISSUES.md` for small tasks that can be proposed as public issues after version 0.2.0 is published.

## Governing boundaries

My Journal remains separate from prompt memory. Collection remains explicitly scoped. Canonical entries remain portable Markdown. Secret redaction remains mandatory. Completion remains validator owned and fail closed.
