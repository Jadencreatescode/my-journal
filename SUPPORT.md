# Support

Use GitHub Discussions for questions, setup help, examples, and ideas. Use the issue forms for reproducible defects, installation failures, feature requests, and compatibility reports.

Before posting, remove credentials, personal information, chat identifiers, absolute private paths, and private conversation text. Prefer the synthetic demonstration when reproducing a problem.

Security vulnerabilities should follow `SECURITY.md` rather than a public issue.

My Journal is maintained as an open source project. Response times are not guaranteed, but focused reports with exact versions and privacy safe reproduction steps are the easiest to act on.
