My Journal turns conversations you explicitly approve into validated daily Markdown. It records decisions, changes, verification, blockers, corrections, and open work without turning the whole journal into agent memory.

Privacy boundary

You choose the scope before collection.

  • Collection is disabled until explicitly enabled.
  • Profiles and platforms use explicit allowlists.
  • Credentials are redacted and common personal information can be masked.
  • Generation uses a restricted Journal toolset.
  • Canonical entries remain portable Markdown that you own.
