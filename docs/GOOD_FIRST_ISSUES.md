# Good first issue candidates

These are intentionally small contribution ideas. Each should become its own GitHub issue with an exact acceptance contract before implementation begins.

1. Add a synthetic weekly summary example under `docs/examples` without changing runtime behavior.
2. Add clearer privacy safe error examples to `SUPPORT.md` for Linux, macOS, and Windows.
3. Add accessibility checks for the static project site, including keyboard focus and reduced motion.
4. Add a release asset inventory viewer that reads only supplied public sidecars.
5. Add tests proving the synthetic demonstration produces byte identical evidence on repeated runs.

Contributors should avoid real conversation data in tests and examples. Use synthetic names, projects, dates, and identifiers only.
